# 沪教版初中英语单词 PK（Word PK）

一款面向沪教版（上海教育出版社 · 牛津版）初中英语的**单词对战学习软件**，
白色液体玻璃（Glassmorphism）风格界面，Windows 桌面程序（tkinter）。

- 收录 **6 册（七上 / 七下 / 八上 / 八下 / 九上 / 九下）共 1556 个单词和短语**，其中 1365 个含国际音标
- 三种对战模式：**双人对战（轮流） / 双窗对战（两个窗口同时 PK） / 人机对战**
- 五种题型：混合 / 看英选中 / 看中选英 / 单词拼写 / 音标PK
- 数字键 1~4 快捷作答、英文朗读、限时作答、单元/册自由选择

## 运行

仅依赖 Python 标准库（tkinter），无第三方依赖：

```bash
python word_pk.py
```

需要 Python 3.8+ 且系统带有 Tk（Windows 官方 Python 安装包默认自带）。

## 打包成 exe

```bash
pip install pyinstaller
pyinstaller --noconfirm --clean --onefile --noconsole --name "沪教版七上单词PK" ^
            --icon "icon.ico" --add-data "icon.ico;." word_pk.py
```

产物位于 `dist/沪教版七上单词PK.exe`（约 8.3 MB）。

## 目录结构

```
├── word_pk.py            # 主程序（含全部界面与游戏逻辑）
├── words_data.py         # 词库（自动生成：6 册 1556 词，含音标）
├── parse_all_books.py    # 词表解析脚本（从教材单词表页面提取）
├── fetch_all_ipa.py      # 音标抓取脚本（有道词典接口，英音优先）
├── build_all_words_data.py  # 词库生成脚本（合并词表 + 音标）
├── make_icon.py          # 图标生成脚本
├── icon.ico / icon.png   # 程序图标
├── words_all_raw.json    # 6 册原始词表数据（源）
└── ipa_all_raw.json      # 音标原始数据（源）
```

## 玩法与计分

- 选择题答对 +10 分，拼写题答对 +15 分
- 双窗对战：两人各用一个独立窗口同时作答同一套题，主窗口为裁判台实时对比比分与用时
- 音标PK = 看音标选单词 + 看单词选音标（英音为主）
- 拼写题给首字母提示，仅出单词不出短语
